# 0.1.10 订单查看与字段对齐

对照用户提供的魔猫淘宝 2.8.31 截图和本地只读分析结果，复用 Element Plus 的固定列、展开行、列宽调整及表格滚动能力。参考表格的字段结构；当前工具的品牌与登录会话保持独立。

| 参考字段 | 本工具显示与来源 |
| --- | --- |
| 订单号、创建时间、商家名 | 默认列；列表原始字段，订单号按字符串保存与复制 |
| 商品、规格、数量 | 一个订单列出全部商品；展开后显示商品/子订单/SKU ID、单价及实付合计，合计不当作单价 |
| 实付款、订单状态 | 同一格显示金额与状态；金额未知与 0 元分别显示 |
| 收货地址、收货电话 | 默认列；地址格同时显示收货人；展开可看完整内容并复制 |
| 物流、物流达签 | 快递公司、可复制单号、已取得的物流状态；未知时保留缺项提示 |
| 付款时间 | 默认列；可另外显示发货、完成时间 |
| 标记、备注、售后 | 默认列显示已采集值；“申请售后”是操作入口，不作为退款状态 |
| 运费、退款金额、账号 | 可通过“显示列”加入；展开详情中也可查看 |
| 详情展开 | 收货、物流、金额/状态、订单时间、商品明细、备注、其他已采集字段 |

## 查看方式

默认保留 12 个数据列，序号、展开箭头及订单号固定在左侧。列可拖动边界调宽，底部横向滚动。窄窗口可用“专注看表”隐藏周围操作区。支持每页 20/50/100/200 条、页码跳转、全结果排序；未知金额始终排在有值项之后。列选择、图片开关与每页条数按平台记忆。

关键词支持订单号、商品、规格、收货人、电话、地址、物流单号及已保存的额外字段，多词同时匹配。可组合状态、商家、缺项与售后筛选。表格显示筛选后金额合计，并单独标出金额未知的数量。筛选仅影响浏览，“导出文件”仍导出所选历史任务的全部记录。

## 淘宝详情来源与边界

“提取订单详情”只打开该任务列表保存的官方 HTTPS 详情链接，校验 URL 中的订单号和正文可见订单号完全一致后才合并。按已观察到的标签读取付款/发货等时间，按官方页面唯一可见的收货和包裹区域读取地址、收货人、电话、快递、运单号及物流状态。复制按钮紧贴订单号的页面结构已有回归测试。等待字段稳定后保存，不读取隐藏数据，不操作交易控件。

遇到登录/平台验证时保留结果并停止，用户自行处理后可继续详情任务。多个同名标签或多个包裹区域不会随意选择某一份覆盖；平台遮蔽的电话按遮蔽结果保存。当前没有实现原版全部独立的物流、备注、售后提取动作；缺失字段仍待核对，不用“无”或“0”冒充结果。打开“平台详情”可自行查看官方页面。

## 本次验证

- 69 项单元测试与 TypeScript/生产构建通过。
- 120 笔合成订单实际 Electron 界面测试通过：组合筛选、搜索、分页与越界回正、展开明细、显示列与图片记忆、大表模式、筛选后仍导出全部任务记录。
- 官方可见详情结构的合成测试通过，验证中断后继续仍读取详情；日志不出现合成收货信息。
- 真实已有淘宝任务中的 1 笔订单提取成功：付款时间、发货时间、收货人、电话、地址、快递、单号、物流状态均写回并显示，订单号与实付款保持不变。13 个任务、19 笔订单记录保留，其他任务未改动。
- 旧品牌有订单目录、新品牌空目录，以及两者均有任务的目录选择测试通过；不复制、移动、删除或合并用户数据库/登录目录。

真实结果只证明该订单的上述可见字段读取成功，不代表各平台所有订单类型与历史范围均已完成验收。安装验收与包校验见 [验证记录](验证记录.md)。
