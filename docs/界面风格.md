# 0.1.11 界面风格

以已有灵兔蓝色 Logo 为视觉基准，使用冷白、浅灰和少量蓝色建立层次。侧栏采用现有图标版 Logo，品牌名称独立排版，避免整张标志在导航区占据过多空间。使用已安装的 Element Plus Icons 统一辅助导航图标。

| 用途 | 色值 / 处理 |
| --- | --- |
| 应用背景 | `#F5F5F7` |
| 内容区域 | 白色，细边框、12 px 圆角、轻阴影 |
| 主文字 / 次级文字 | `#1D1D1F` / `#63636A` |
| 主要操作与选中状态 | `#0071E3`，浅蓝底色 |
| 成功 / 待处理 / 错误 | 语义绿色、琥珀色、红色，保留文字状态 |
| 表格 | 减少纵向网格线，保留横向分隔、隔行底色、固定列与悬停提示 |
| 执行日志 | 浅色控制台、等宽文字，按级别区分状态颜色 |

窗口使用 Electron 的 `titleBarStyle: hidden` 和 Windows 原生 `titleBarOverlay`，统一标题区域背景。窗口按钮由系统保留，顶栏可拖动；更新链接使用非拖动区域。大表模式给原生窗口控制区留出空间。

现有列、筛选、分页、展开详情、日志设置和导出流程保留。支持键盘焦点描边和系统减少动态效果偏好；小窗口列菜单向上展开并允许滚动，大表模式向下展开。

## 参考与验证

- [Apple 色彩设计指南](https://developer.apple.com/design/human-interface-guidelines/color)：限制界面强调色，使用语义颜色表达状态。
- [Apple 材质指南](https://developer.apple.com/design/human-interface-guidelines/materials)：通过背景和层次区分导航、控件与内容；订单表以清晰阅读为优先。
- [Electron 自定义标题栏](https://www.electronjs.org/docs/latest/tutorial/custom-title-bar)：复用原生窗口按钮。
- [Element Plus Icons](https://element-plus.org/en-US/component/icon.html)：复用现有图标组件。

TypeScript 与生产构建通过；订单浏览、九个平台切换及 Excel 导出、执行日志三组现有 Electron 回归通过。使用合成数据检查正常、最小窗口、大表、详情、列菜单、设置、教程、历史和空状态；普通窗口分页可见，最小窗口无整页横向溢出，列菜单不覆盖标题控制区或超出窗口。

升级前后数据与安装包校验见 [验证记录](验证记录.md)。说明截图均为合成数据。
