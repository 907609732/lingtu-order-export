# 五平台订单详情（0.1.18）

淘宝／天猫、1688、拼多多、京东、闲鱼页面均提供“提取订单详情”。正常完成列表并且有待读取订单时显示蓝色强调与数量；遇到验证或正在采集时不误报完成。详情读取成功后减少待提取数，失败仍可继续；未提供字段保留缺项。

- 淘宝：保留原有官方详情页面读取。
- 1688：请求官方订单导出服务，等待官方 XLSX，再按精确订单号合并收货、物流、时间与备注。只合并当前任务已有订单，不将额外日期或其他订单加入表格。保存导出任务时间与旧文件指纹，暂停或重启后继续等待同一个文件，避免重复创建。
- 拼多多、闲鱼：复用现有平台详情逻辑，支持单独补全与失败继续。
- 京东：打开列表中实际提供的官方详情链接，校验链接与页面订单号，再读取可见字段。不猜测未知接口，不将未获取字段标为完整。

1688 使用淘宝／阿里账号登录，官方可能展示淘宝登录页面。不要把登录页误认为切换平台；完成登录后若落到淘宝首页，新版会返回 1688。登录、验证码仍由用户操作。最多自动返回两次，避免循环跳转。

## 来源与边界

独立实现参考本机 REA 留存证据 `.research/tborder-two/docs/2026-08-04.md` 中 1688 官方导出请求及结果结构，以及原软件导出列名。未使用旧版未绑定请求参数的 queryOrder 猜测实现。参考证据仅用于协议与字段核对，不复制原商业软件业务代码。

新实现通过隔离网络与合成订单测试；尚未完成五个平台真实账号详情验收。1688 的官方文件生成速度、可下载时间与表头可能变化；未知结构停止并保留数据。京东页面未提供详情链接或字段时仍需后续现场适配。

0.1.18 已使用当前 1688 买家订单入口，修复旧入口跳到淘宝错误页的问题。官方账号登录框仍可能带有淘宝品牌，这是 1688 页面内的登录流程。
