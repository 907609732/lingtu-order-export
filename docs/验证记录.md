# 0.1.2 日志功能验证记录

验证日期：2026-10-13 至 2026-10-14（测试跨零点）。环境：Windows 11 x64、Node 24.18.0、Electron 44.7.0。

## 功能与验证

- 使用 electron-log 5.4.4，日志默认关闭，设置开关立即生效且通过 SQLite 持久保存。
- 日志包含采集页数/记录数量、操作开始/结束、导出结果、主进程与界面异常、网络加载/辅助代理异常。
- 写入采用字段白名单，异常仅保留类别、已知代码及程序内位置；不落盘任意异常原文、账号/订单号/订单正文、收货信息、Cookie、Token、完整网址或文件路径。
- 当前日志与上一份日志各约 5 MB，自动轮换。关闭后停止新增，保留已有日志。
- 24 项单元测试通过（18 项既有业务测试 + 6 项日志测试），包括磁盘写入失败后的业务不中断与重新开启恢复。
- TypeScript 检查和生产构建通过。
- `node tests/logging-smoke.mjs`：实际 Electron 设置开关、默认关闭、开启写文件、界面和 IPC 异常、敏感内容排除、打开文件夹 IPC、开启/关闭两种状态的重启记忆，以及关闭后退出/启动均不写入通过。该自动测试中的打开目录调用做了拦截，未用它作为系统资源管理器已打开的证据。
- `node tests/collectors-smoke.mjs`：五个平台合成采集与日志记录通过，平台网页的 Node/IPC 隔离通过，日志不包含测试订单与收货字段。
- `node tests/desktop-smoke.mjs`：九个平台界面、实际 Excel 导出、长订单号/金额/缺项表及数据持久化回归通过；导出结果写日志但订单正文不写入。

- 实机发现从 MSIX 宿主启动时，AppData 被重定向，原始逻辑路径交给 Explorer 会提示位置不可用。已通过 Node `realpathSync.native` 返回实际目录，用于设置页和打开目录按钮；不迁移任务或登录数据。参考：[Microsoft MSIX 文件系统重定向说明](https://learn.microsoft.com/en-us/windows/msix/desktop/desktop-to-uwp-behind-the-scenes)。
