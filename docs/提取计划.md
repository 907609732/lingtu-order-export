# 提取计划（0.1.15）

支持淘宝／天猫、1688、拼多多、京东、闲鱼。点击顶部“提取计划”，默认带入当前日期范围，按月或按天生成日期段。取消不需要的标签后开始；同一计划合并成一个历史任务和一张订单表，导出包含该计划全部已取得订单。

这是手动启动的分批提取，不是每天或指定时刻自动运行。日期按北京时间解释，首尾月份仍受所选日期约束。

运行中可暂停。验证、限流、账号变化或网络异常会保留结果与断点，处理后手动继续。关闭软件停止执行，下次打开恢复为暂停。已经完成的查询分组不重复采集。历史任务选中后点击“计划进度”可重新查看。

日期标签：待提取、提取中、列表已完成、已暂停、需要处理。绿色只说明对应列表正常读取结束；空结果也可完成，达到分页上限和异常不会标记完成。

淘宝列表正常结束且有待读取详情时，“提取订单详情 · N”蓝色强调，并显示文字提示。手动点击后逐笔读取；成功订单不再计入待提取数量，失败订单可重试。平台未返回的字段仍标记缺项。旧任务没有明确完成记录时不自动高亮。

平台查询分组：淘宝按月、京东按年、1688按选中区间、拼多多和闲鱼一次遍历覆盖范围。入库时再次过滤未选日期，订单号合并去重。清理平台缓存会同时删除该平台的计划，已导出文件保留。

## 验证边界

- 单元测试覆盖日期裁剪、跨年、闰日、重复选择、不连续日期过滤、订单去重、详情提醒、清理与断点恢复。
- 五个平台的计划执行状态分别模拟正常结束、空结果、分页上限、网络异常、登录验证、限流、账号变化与暂停恢复。
- 网络隔离的 Electron 测试运行五个平台真实适配器，使用合成响应验证查询分组和正常完成。
- 界面测试验证取消中间月份、合并结果导出、详情读取后提醒消失，以及 1120×740 和 2560×1392 布局。
- 原有订单浏览、详情中断重试、Excel 导出和持久化重启回归通过。
- 本轮未使用真实账号重新执行五个平台的提取计划；模拟测试不等同于真实平台验收。
