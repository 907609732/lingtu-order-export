# 本机 AI 调用设计

用户已选择本地 API + MCP，并要求直接实现，主要供 Codex 使用。

- 复用 Electron 主进程现有操作，UI 和 API 共享并发、更新和平台检查。
- API 只绑定 127.0.0.1 随机端口，Bearer 密钥每次启动重建；连接描述文件仅存于用户本机，不提交。
- 拒绝浏览器 Origin、非本机 Host、超大请求、未知操作和无效参数。不提供删除、支付、下单、系统代理修改或凭据读取。
- 暴露状态、任务、分页订单、打开登录窗口、开始/暂停/继续/重试/详情补齐和导出。登录及验证码仍人工处理；不能将任务完成误报为平台范围已验证。
- MCP 使用官方 TypeScript SDK 的 stdio transport，读取本机连接文件，再调用 API。任务数据只白名单返回，不返回 Cookie 或官方导出凭据。
- 对比：仅 HTTP 需要 AI 自行理解接口；仅 MCP 不方便其他程序。所选双层方式共享同一业务执行入口，避免重复采集逻辑。
- 兼容现有 Electron/Vue/TypeScript；独立打包 Node MCP 文件，随 Windows 软件附带，提供 Codex 注册说明。
- 验收：HTTP 鉴权/输入/重启/脱敏测试、真实 MCP 协议测试、隔离 Electron 合成任务导出、完整测试及构建。发布源码到 GitHub 并检查 Gitee 同步，不发布新正式版本。
