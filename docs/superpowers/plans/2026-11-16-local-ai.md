# Local AI API and MCP Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans inline, with test-driven-development and one final independent review.

**Goal:** Codex can invoke the running local order exporter safely.
**Architecture:** Loopback authenticated HTTP dispatches existing Electron actions. A bundled stdio MCP adapter shares input schemas and reads a rotating connection descriptor.
**Tech Stack:** Node HTTP, Zod, official MCP TypeScript SDK, Vite, Vitest, Playwright Electron.
**Spec:** docs/superpowers/specs/2026-11-16-local-ai-design.md

## Global Constraints
- Preserve unrelated uncommitted 1688 work in the original checkout.
- Bind only 127.0.0.1; no cloud deployment or real collection in tests.
- Never commit connection credentials or account/order data.

## Review Focus
- Browser-origin requests and hostile Host headers must fail before dispatch.
- Invalid dates, unknown operations and excessive bodies must not mutate tasks.
- Task cookies and official export tokens must never appear in returned state.
- App restart rotates the key and MCP rereads discovery on every call.
- UI and AI operations must share existing busy/update checks.
