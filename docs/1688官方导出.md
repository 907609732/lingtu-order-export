# 1688 官方导出

在1688页切换“模式二 · 官方导出”，选择月份后点击“②官方导出”。软件操作官方页面申请报表，等待生成并下载，再按报表中的订单创建时间筛选所选月份、导入并展示核对结果。普通采集任务与官方导出任务分开保存。

依据本次接收的页面适配资料，官方报表可能包含账号全量订单，因此以下载内容做本地月份筛选。金额为报表内部的实付合计，不代表已与官网金额二次核对；“范围完整性未核实”不能视为平台所有订单均已核对。核对面板保留报表行数、唯一订单数、导入数、范围外记录、缺项及警告。有效报表在所选月份没有订单时可完成空结果。

遇到登录或滑块验证会暂停，手动完成后继续。正常已确认的报表申请可续接下载，避免重复生成。提交结果不明确、导出记录重复或同时出现多个新记录时停止自动操作，不猜选历史报表。导出期间请勿在其他窗口同时申请1688报表。官网操作阶段需保持软件页面可操作；切换平台或窗口导致无法输入时会保留进度并提示继续。

默认安装后即可使用，无需配置环境变量。维护时可用 `ORDERDESK_ALIBABA_OFFICIAL=0` 显式停用；该配置不删除历史订单和任务。

本次修复复用项目既有 Electron WebContents/DownloadItem、ExcelJS、Vue 与 Vitest，没有新增依赖。下载接管依据 [Electron WebContents 文档](https://www.electronjs.org/docs/latest/api/web-contents)及 [Session will-download 文档](https://www.electronjs.org/docs/latest/api/session)。

验收使用独立用户目录、合成页面和工作簿，不读取真实账户订单，不访问真实1688页面。DeepSeek交接中的真实页面测试记录属于上游提供的证据，本次没有独立复验真实站点。发布验收还包括云端Windows构建、下载校验及打包后的隔离功能测试。

本地修复验收：263项单元测试、8项更新资产测试、生产构建通过；真实Electron隔离测试通过普通视图切换、生成前暂停与继续、不连续月份导入、空月份完成、连续任务、旧记录排除及原生下载。独立代码审查未发现剩余的发布级问题。

0.1.23弹窗兼容修复：读取申请前的导出记录后，通过同一受控官方入口重新加载订单页、恢复日期并重新核对总数，再打开生成报表弹窗。生产流程不依赖官网关闭图标的标签或样式；停止、账号校验与提交前断点保持不变。回归夹具不提供任何可识别关闭按钮，防止只覆盖带文字的简化弹窗。普通采集恢复翻页1.5秒、时间段间隔1.6秒、详情报表轮询10秒，验证码暂停逻辑保留。

0.1.24继续简化全量报表路径：生产流程不再操作官网日期控件，也不把页面当前可见数量当成全量报表数量。所选月份仅绑定在本地任务、解析和导入阶段；搜索阶段明确声明账号报表模式、数量未知，范围完整性始终未独立核实。回归页面同时移除日期控件和关闭按钮，原生下载、所选月份过滤、空月份及暂停续接仍需通过。
