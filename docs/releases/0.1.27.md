# 电商平台采购订单导出 v0.1.27

## 修复

- 修复 1688 官方导出后切回普通采集时，误报“请先暂停当前平台任务”的问题；普通采集、补齐详情和打开订单详情共用正确的任务运行标识。
- 修复官方详情报表已经生成，软件却一直显示等待的问题。匹配允许平台时间的短暂差异，并保留旧报表排除、唯一候选和冲突保护；已有申请可以继续处理，不需要重复生成报表。
- 时间匹配不依赖电脑与平台时钟完全一致。
- 整合此前合入主干的 1688 官方导出、月份筛选、下载来源与断点恢复修复。

## 本机 AI 调用

- 提供带访问密钥的本地 API 和 MCP，供 Codex 等本机 AI 客户端查询任务、启动/暂停/继续采集、补齐详情和导出文件。
- 仅监听本机回环地址，不提供远程接口，不返回登录 Cookie 或官方报表下载令牌。
- 软件附带独立 MCP 程序及接入说明；MCP 需要系统 Node.js 22 或更新版本，软件本身无需另装 Node.js。
- [MCP 接入说明](https://github.com/907609732/lingtu-order-export/blob/v0.1.27/docs/LOCAL_AI.md)

## 验证与升级

- 本地 291 项单元测试、8 项更新资产测试通过；五个平台的真实 Electron 隔离详情测试通过。
- 已在真实 1688 账户验证普通采集、官方报表读取、收货/物流信息补齐及 Excel 导出。平台原报表中的空值仍保留，任务范围和其他缺项以软件提示为准。
- Windows x64 完整安装包升级，保留原有本机任务、订单、登录和设置。
- 发布附件包含安装器和 `latest.yml`；安装器与清单经哈希及版本核验后公开。
