多平台订单导出：选择平台，在官方页面登录，按下单日期采集历史订单，最后导出 Excel 或 CSV。以下截图使用合成演示数据。

01 / 安装与准备

  1. 在官网下载区域进入 GitHub Release，下载 Windows x64 的 Setup.exe 安装包，不要将源码 ZIP 当作安装包。
  2. 运行安装程序，完成后打开“电商平台采购订单导出”。
  3. 准备需要核对的订单日期，以及用于对照的官方订单页面。建议先选订单较少的一天。

当前公开版本：请查看发布页。文件：以 Release 为准。

安装包未配置代码签名，Windows 可能显示未知发布者。请核对下载来源与官网提供的 SHA-256 后，自行决定是否安装；无需关闭系统防护。

02 / 选择平台并登录

  1. 点击左侧需要整理订单的平台。不同平台的登录状态各自独立。
  2. 点击“登录 / 查看平台页”，在软件打开的官方页面中自行登录。
  3. 完成扫码、短信或平台要求的其他验证，再返回软件工作台。不要向他人提供验证码、Cookie 或账号密码。

淘宝 / 天猫、1688、拼多多、京东、闲鱼使用平台页面读取。完整平台列表见支持平台。

得物、快手、饿了么、美团通过微信小程序辅助采集。首次使用涉及本机证书和系统代理，请阅读软件内步骤、自行确认并记录原设置，完成后恢复原代理；软件不会自动替你完成证书信任或系统代理切换。请根据需要选择对应平台。

03 / 按下单日期采集

  1. 选择开始日期与结束日期。筛选依据是订单的下单时间，不是付款、发货或收货时间。历史订单需要选择对应历史日期。
  2. 点击“开始采集”。在“执行日志”查看当前读取步骤、页数与累计订单数。
  3. 采集后查看订单明细，按需提取详情，再选择格式与目录导出。

日志等待提示不代表采集失败。遇到登录或验证提示，先完成官方验证，再按软件提示继续；不要反复点击开始创建重复任务。没有订单时先核对日期，而不是直接认定登录失效。

04 / 查看订单，补全详情

订单表可搜索商品、规格、物流等信息，使用状态与商家筛选；通过“显示列”选择字段，“专注看表”展开大表。点击订单号可展开明细，也可打开官方详情页面。

淘宝、1688、拼多多、京东、闲鱼已有订单可点击“提取订单详情”，读取官方页面可见的收货、物流与时间字段。若遇到验证，按日志提示在官方页面自行完成，再继续处理。

详情读取只能获取平台页面实际提供的信息。未获取、待提取、售后缺项或多包裹情况，需要进一步核对，不会自动填充猜测值。

05 / 导出 Excel 或 CSV

  1. 新版在“导出设置”中选择格式、商品图片选项和保存目录；旧版请在采集页或“保存与设置”中寻找对应选项。
  2. 选择 Excel 可嵌入商品图片；选择 CSV 便于作为纯文本表格处理，不嵌入图片。
  3. 点击“导出文件”，等待日志提示文件写入完成，再到所选目录打开文件核对。

表格筛选只影响浏览，导出始终包含当前任务全部订单。若需指定日期的订单，请采集对应日期范围再导出。财务对账需另结合付款、退款和平台账单。

图片获取失败时保留图片链接，并记录缺项说明。导出按平台分目录并附时间戳；仍建议保留原始导出文件，在副本中做后续编辑。

06 / 找回已有任务

点击左下角“导出任务”，按平台、日期和订单数量找到对应记录，再点击查看。可以重新打开已获取的结果，按任务状态继续处理或重新导出。

平台采集缓存与已经导出的文件相互独立。清理平台缓存会影响该平台的本机任务及订单，请确认后再操作；已经导出的文件保留。

异常处理 / 先看提示，再继续

日期范围内读取到 0 笔订单

对照官方页面确认该范围内确有订单，并检查是否选了正确平台。日期按下单时间计算，可先缩小到已知有订单的一天；仍无结果时，保留日期范围、版本和脱敏日志用于反馈。

需要登录、验证码或扫码验证

打开“登录 / 查看平台页”，自行完成官方页面的验证，然后返回软件按提示继续。请勿上传验证码、Cookie、Token 或完整账号信息。

读取中断、请求受限或长时间等待

查看执行日志中的当前步骤与错误类别。检查网络，按提示暂停或稍后继续，保留已有任务；出现平台限制时减少重复操作，不要尝试绕过验证。

收货、物流或售后字段缺失

可使用“提取订单详情”，再核对官方详情页。平台页面未提供或接口变化时，相关字段可能缺失。多包裹和特殊订单需要人工核对。

图片缺失，或导出后找不到文件

先查看写入完成提示及“导出设置”里的目录，旧版可查看“保存与设置”。图片失败时核对链接和缺项说明。文件保存失败时换到你有写入权限的目录后重试，不要删除已有任务。

如何提交有用的问题反馈？

在“保存与设置”开启问题排查日志，复现一次后打开日志文件夹。到 GitHub Issues 提交版本、平台、日期范围、操作步骤和错误类别，上传前检查并遮挡账号、订单、收货信息、本机路径及任何凭据。

数据与隐私 / 留在自己的电脑

订单与登录状态保存在本机；实际数据与日志位置以软件“保存与设置”页面为准。问题排查日志可开关，不会自动上传；导出文件保存在你选择的目录。

软件正常使用会访问平台页面、平台图片与 GitHub 更新接口。目前配置了匿名启动统计，向自建后端发送随机设备编号、版本与时间，不包含账号、订单或收货信息。官网不增加访问统计脚本。

请仅整理你有权访问的订单，保管导出文件，并在对外分享前遮挡敏感字段。软件为独立第三方工具，与所列电商平台无隶属关系。
